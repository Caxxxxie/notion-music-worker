# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities or leaked credentials. Use the repository's private vulnerability reporting form under **Security** > **Advisories** > **Report a vulnerability**.

Include the affected endpoint or component, reproduction steps, impact, and any suggested mitigation. Do not include live tokens or other credentials in the report.

Security fixes are applied to the latest version. This project does not currently maintain older release branches.
